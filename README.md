# ScreenShotPlus

Windows 10/11 的区域截图小工具：截图自动保存 PNG，拖动浮动缩略图即可向支持文件拖入的程序分享。

v1.4.0 加入五档动画强度与独立的动效设置页。滑块采用强调色轨道、圆形滑块和文字淡入滑动；终极档切换为蓝紫渐变与流动星光，先短暂显示 `XuanRikka`，再切换为“终极”。鼠标拖动、方向键、Home / End 都可选择档位。滑块本身始终动画响应，轻度档或 Windows 关闭动画也不会冻结它。

| 强度 | 实际效果 |
| --- | --- |
| 轻度 | 停用应用装饰动画，直接呈现状态；保留设置滑块动画 |
| 中 | 克制的淡入、轻微位移与拖动卡片，省略截图飞入 |
| 高 | 图片飞入、回弹、指针跟随与倾斜，默认档位 |
| 极高 | 更明显的层次、运动幅度与悬浮卡片流光 |
| 终极 | 专属渐变星光滑块、卡片星光与启动品牌演绎 |

保存终极档后，下一次手动启动会读取配置，呈现光晕、星光、截图标记展开、品牌文字出现与操作按钮依次入场。动画期间可以点击操作中断揭幕；关闭启动动画、降低档位或 Windows 减少动态效果时省略这段演绎。`--tray` 自启动保持安静。取消设置会恢复预览之前的动画档位、速度与强调色。

v1.3.0 将截图与分享串成完整动效：唤起时桌面遮罩渐入、顶部提示条弹性展开，十字辅助线帮助定位；框选时出现柔光角标与尺寸浮签；完成后图片沿弧线飞入缩略图，预览轻弹落位并绘制保存勾号。拖动时图片抬起为带阴影的透明悬浮卡片，跟随指针并轻微倾斜；接收方允许复制时显示绿色“松开即可复制”，放置后收拢淡出，取消时飞回原预览。原截图文件始终保留。

悬浮卡片不抢焦点，也不拦截底层窗口的鼠标命中；可接收状态来自 OLE 的实际 `DROPEFFECT` 反馈。新截图开始前会清除悬浮效果并等待桌面合成，效果不会进入下一张截图。截图遮罩缓存暗化桌面，由窗口合成完成入场透明度过渡；渐入期间会透出下方实时桌面，最终裁剪始终读取启动截图时冻结的原图。提示卡、选区和尺寸标签按脏区域刷新，避免每帧在 CPU 上混合整张桌面。动态效果按显示器刷新率调度，获取失败默认 120 FPS；负载较高时跳过过期帧，仍按实际时间完成动作。系统关闭动画效果时省略应用装饰性过渡和悬浮卡片。

v1.2.0 更新了现代深色自绘界面：柔和渐变、圆角描边、窗口淡入、按钮悬停与按压回弹、滑动开关、预览图片轻微缩放，以及 RGB 调色板展开/收起。保留绿色截图品牌色，关闭按钮悬停使用红色反馈。

动画以窗口当前所在显示器的刷新率为目标，支持 59.94 等小数刷新率；查询失败时默认 120 FPS。窗口跨屏、显示设置或 DPI 改变后会重新读取。使用高精度等待计时器和基于实际时间的缓动，动画时长不随帧率改变；实际绘制速度仍取决于系统调度和设备性能。Windows 关闭“动画效果”或启用高对比度时，应用装饰动画直接显示最终状态，设置滑块仍按用户要求独立动画。静止、隐藏或最小化的窗口停止动画刷新；终极设置页仅在该页面可见时刷新星光，离开页面或关闭窗口会停止。绘图缓冲和缩放图片按窗口尺寸/DPI 缓存，截图与标注保存仍使用原图物理像素。

## 使用

1. 运行 `ScreenShotPlus.exe`。关闭操作面板后，程序仍在系统托盘运行；左击或右击托盘图标可打开面板。
2. 按 `Ctrl+Shift+S` 或点击“开始区域截图”。左键拖动框选，松开保存；Esc、右键或切换应用取消。
3. 从浮动预览的图片区域拖入文件夹、QQ、微信或浏览器附件区。接收程序可以将 PNG 当作图片或附件；原始截图始终保留。
   单击图片可进入编辑界面；按住并拖动仍直接分享。
4. 点击缩略图右上角关闭预览；操作面板的“显示最新截图”可重新显示本次运行中最新的截图。
5. 要结束程序，请在操作面板点击“退出程序”。重复启动会打开现有实例。

v1.1.1 增强了命名互斥锁：同一登录会话内的不同目录、不同版本共用单实例锁。重复手动启动会等待主窗口就绪并唤出已运行的面板；重复 `--tray` 启动安静退出。退出程序释放锁后可以重新启动。

托盘使用绿色截图标记。图标注册失败时会每 2 秒重试并保留可操作的面板，避免后台程序没有入口；Explorer 重建任务栏后会重新注册。Windows 可能将已注册图标放在通知区域的隐藏图标中，图标能否固定到任务栏由 Windows 设置控制。

程序会检测低完整性运行状态。当前开发仓库被设置了 Windows 的 Low 完整性标签，输出 EXE 也继承该标签：即使通过资源管理器启动原路径，进程仍然受限，托盘注册、普通配置目录及启动项写入可能被拒绝。重新构建，或者解压到本仓库内的另一目录，都不会改变此限制。发布后的运行环境需检查 EXE 及其所在目录的实际完整性标签，不能仅根据“已解压”或“手动启动”判断。普通用户权限即可，不需要将应用改为要求管理员运行。

截图默认保存到系统“图片”目录的 `ScreenShotPlus` 子目录，文件名包含日期、时间、毫秒及必要的冲突序号。程序不会覆盖已有截图，也不会自动清理文件。

## 设置

- 动效：轻度 / 中 / 高 / 极高 / 终极；敏捷 / 均衡 / 舒缓三种节奏；启动、截图唤醒与完成转场、拖动图片与落点反馈可分别关闭。调整档位与速度即时预览，保存后持久生效。
- 外观：薄荷、晴蓝、鸢紫、玫瑰、流金五种强调色；缩略图可停靠四角，支持紧凑、标准、宽阔三种尺寸。强调色即时预览，位置和尺寸保存后用于后续预览。
- 截图：背景暗度 25%–80%，支持鼠标滑动和方向键微调；截图准星可关闭。设置页提供自绘外观预览，实际尺寸标签和原始 PNG 像素始终保留。
- 保存目录：通过系统文件夹选择器更改，支持中文和空格。
- 快捷键：点击快捷键行，然后按 Ctrl / Alt / Shift 与字母、数字或 F1–F24 的组合。Esc 取消录入。
- PrintScreen：默认关闭，可与组合键同时启用。如仍触发系统截图，请关闭 Windows 设置中“使用 Print Screen 键打开屏幕捕获”的选项；其他软件占用时会提示注册失败。
- 缩略图：默认保留到关闭或下一次截图。点击切换为 5、10、15、30、60 或 120 秒；悬停、按住图片和拖拽期间暂停倒计时。
- 开机自启动：勾选并保存后，为当前用户注册启动项，登录 Windows 时通过 `--tray` 直接进入托盘。取消勾选并保存会移除启动项；手动启动仍显示面板。移动便携 EXE 后，请重新保存设置以更新路径。Windows 启动应用设置或组织策略可能阻止自动启动。
- 配置默认保存在 `%LOCALAPPDATA%\ScreenShotPlus\config.json`。如果该位置不可写，保存设置会自动回退到 EXE 旁的 `ScreenShotPlus-data\config.json`，后续启动优先读取便携配置；设置页会显示当前配置文件路径。移动便携 EXE 时请一起保留该数据目录。两处均失败会显示具体操作、错误码与路径，原设置继续有效。点击“保存设置”才写入；无效或损坏的配置会提示并使用默认值。

截图写入失败时，图像会保留在内存中。更换保存目录并保存设置会自动重试，也可点击“重试保存未保存的截图”。退出程序或完成另一张截图会丢弃尚未保存的旧图像。

## 图片标注

- 画笔：预设赤、橙、黄、绿、青、蓝、紫；使用 − / + 调整 1–40 px 粗细。单击画布画点，按住拖动画线。
- RGB 调色板：点击“RGB 自定义颜色”，拖动 R/G/B 滑条。上下方向键选择通道，左右方向键按 1 微调，范围 0–255；同一颜色也用于文字。
- 文字：选择“文字”，点击图片放置文字，然后输入。支持 Unicode、中文输入法接口、Ctrl+V 粘贴和退格；Shift+Enter 换行，Enter 或“完成文字”结束。用 − / + 调整 8–160 px 字号，点击色块或调色板更改颜色。在本次编辑中，点击已有文字可修改内容、颜色和字号；清空后完成会删除该文字。
- 撤销：点击“撤销”或 Ctrl+Z，最多保留 24 次标注操作；正在输入时先取消该次文字修改。Esc 或“取消”放弃本次编辑，返回上次保存的缩略图。
- 保存并返回：以原图分辨率另存 PNG，原截图保留；弹窗会立即使用编辑后的图片，继续通过文件拖放分享。写入失败会保留编辑内容，可再次点击保存重试。

保存后标注已合并为图片像素；再次打开可以追加标注，无法单独修改上一次保存的文字或线条。窗口按 DPI 和显示器工作区适配，画笔粗细、字号和标注位置始终按原图物理像素保存。

## 构建

需要 VS 2022 的 C++ 桌面开发工具、MSVC v143、Windows SDK，以及 vcpkg。默认从 `%USERPROFILE%\vcpkg` 查找，也可以设置 `VCPKG_ROOT` 或传入 MSBuild 属性 `VcpkgRoot`。

打开 `ScreenShotPlus.sln`，选择 **Release / x64** 并构建。项目通过固定 baseline 的 vcpkg manifest 自动获取 `nlohmann-json`，使用 `x64-windows-static` 与静态 CRT；截图、GDI+ 和 OLE 拖放使用系统库，不依赖 WinUI 3 或 .NET。

也可在仓库目录运行：

```powershell
.\tools\build.ps1
.\tools\build.ps1 -Test
.\tools\build.ps1 -Configuration Debug
```

托盘诊断：`tools\tray-probe.ps1` 在当前 PowerShell 进程中注册并立即移除自己的诊断图标，打印进程/Explorer 完整性及真实图标矩形。测试 EXE 的 `--tray-probe` 则使用原生 C++ 进程打印自身完整性、结构大小、窗口/图标参数及注册结果。两者用于定位文件标签导致的不同权限；单独的探针成功不代表应用托盘已经通过验收。

实际运行状态核查：执行 `.\tools\inspect-runtime.ps1`，默认检查 `x64\Release\ScreenShotPlus.exe`，列出所有正在运行的 ScreenShotPlus 的完整路径、父进程、会话和实际进程完整性，以及主面板的托盘注册标记和 Shell 图标矩形。可通过 `-ExecutablePath` 指定另一份 EXE。该脚本只读取状态，不启动/关闭应用、不注册图标，也不修改任何安全标签；它能区分“文件带 Low 标签”和“当前运行的进程确实是 Low”。

旧版不提供托盘注册标记，不能将标记缺失直接判为注册失败；Shell 的 GetRect 成功且矩形有效才是实际图标存在的证据。测试新版本前需退出旧实例，否则单实例锁会唤出现有版本。

交付以 `x64\Release\ScreenShotPlus.exe` 为准，由用户直接发布；日常工作不打包、不更新 dist。构建脚本会输出本次 EXE 的完整路径与版本。只有用户明确要求打包时才使用 `-Package`；EXE 运行仅依赖 Windows 系统 DLL。

## 验证范围

独立测试工程 `tests\ScreenShotPlus.Tests.vcxproj` 覆盖区域坐标、配置读写和损坏回退、PNG 像素与尺寸、中文路径、文件名唯一性、真实文件权限拒绝、保存失败、OLE 文件数据、实际桌面裁剪、取消、GDI 资源释放、悬停/拖拽计时暂停、真实热键冲突与事务回退、应用内自动保存、设置持久化、重复触发、单实例和退出。首版实际结果见 [VERIFICATION.md](VERIFICATION.md)。

测试会短暂显示本程序的测试窗口，在 `build\test-artifacts` 保存自己的界面图像和测试文件。检测到现有运行实例时会明确打印 `SKIP`，跳过窗口测试；也可直接向测试 EXE 传入 `--no-ui`。QQ、微信、资源管理器、浏览器真实附件区、不同权限进程之间的拖入，以及混合 DPI 多屏仍需人工验收，模块测试不代表这些客户端已通过。

新增用例覆盖预设颜色切换/RGB 画笔、文字绘制和修改、字号、撤销、取消、保存失败重试、编辑 PNG 的文件传输数据及截图→编辑→预览流程。测试 EXE 的 `--isolated-ui` 参数允许已有实例运行时验证测试进程自己的窗口，使用独立配置和快捷键，并跳过单实例测试。界面图像直接由本程序绘制到测试缓冲区，不受其他窗口遮挡影响。

动画用例覆盖小数刷新率与 120 回退、60/120/144/240 Hz 的时长、过渡中断与反向、减少动态效果、帧消息调度、空闲/隐藏停止、重开窗口和 GDI 资源释放。可单独运行 `build\tests\Release\ScreenShotPlus.Tests.exe --animation-ui`；测试不会更改系统的动画设置。实际多屏切换和不同显示器刷新率仍需在对应硬件上验收。

`--animation-ui` 同时包含图片飞入、透明拖动卡片、允许/不可接收提示、取消回位、放置收拢、输入穿透、焦点与资源生命周期的独立窗口用例。其中接收状态由用例注入，仅验证视觉流程；QQ、微信和浏览器的真实拖入仍需客户端验收。完整窗口回归另验证唤起/框选界面、反向选区的物理坐标，以及动画后的 PNG 原始像素。

五档设置用例验证轻度下滑块仍动画、短暂署名与最终文字、快速反向拖动、键盘与鼠标捕获、即时预览回滚、全部自定义选项保存和重开资源释放。启动用例通过独立测试进程的真实应用窗口读取隔离配置，验证终极入场、独立关闭、低档省略和安静托盘启动；不改用户配置或自启动项。新增截图外观图像只使用测试程序自己的蓝色桌面图案。

当前不包含录屏、滚动截图和历史管理。截屏使用桌面 GDI 捕获，受保护的视频内容、HDR 色彩还原及安全桌面不在支持范围内。
