# ScreenShotPlus

适用于 Windows 10/11 x64 的便携截图工具。框选后自动保存 PNG，可以编辑标注，也可以从浮动预览直接拖动分享。

## 开始使用

1. 运行 `ScreenShotPlus.exe`，按 `Ctrl+Shift+S` 或点击“开始区域截图”。
2. 按住鼠标左键框选，松开后自动保存；按 Esc、右键或切换应用取消。
3. 单击浮动预览的图片进入编辑；按住图片拖动，可以分享给支持文件拖入的程序。
4. 关闭操作面板后，程序继续在托盘运行。点击托盘图标可重新打开面板。
5. 需要结束程序时，点击操作面板中的“退出程序”。

截图默认保存到系统“图片”目录下的 `ScreenShotPlus` 文件夹。文件名包含日期和时间，不覆盖已有截图，也不会自动清理文件。重复启动会打开已有实例。

## 预览与分享

- 从图片区域拖入文件夹、聊天窗口或浏览器附件区。能否接收、显示为图片还是附件，由接收程序决定。
- 单击图片打开编辑工作台；右键图片可在资源管理器中选中对应文件。
- 点击预览右上角关闭；操作面板中的“显示最新截图”可以重新打开本次运行中最新的截图。
- 可以关闭文件名和操作提示，调整预览尺寸与停靠位置。
- 可开启“分享成功后收起缩略图”。取消拖动或接收失败时，预览继续保留。

拖动分享和关闭预览都会保留原 PNG 文件。

## 编辑图片

打开预览图片后，在左侧选择工具，完成后点击“保存并返回”，或按 `Ctrl+S`。编辑结果以原图分辨率另存为 PNG，原截图保留。

| 工具 | 操作 |
| --- | --- |
| 画笔 | 单击画点，拖动画线 |
| 箭头 | 从起点拖向终点 |
| 矩形 | 拖动框选；按住 Shift 绘制正方形 |
| 马赛克 | 拖动框选遮盖区域，选择 8、16、24、32 px 块大小 |
| 文字 | 点击图片放置文字，点击已有文字或在选择工具下双击可修改 |
| 选择 | 拖动移动标注；拖动箭头端点、矩形或马赛克角点调整；Delete 删除 |

### 调整大小和颜色

- 拖动属性区滑条快速调整粗细或字号。
- 点击数值直接输入，Enter 应用、Esc 取消；按住 − / + 可以连续微调。
- 画笔、箭头和矩形粗细支持 1–40 px，文字字号支持 8–160 px。
- 选择预设颜色，或展开 RGB 面板调整颜色；已选标注可以直接修改大小和颜色。

### 查看画布

- 鼠标滚轮围绕指针位置缩放；底部可以切换“适应画布”和“100%”。
- 空格配合左键拖动，或按住中键拖动，可以平移画布。
- 100% 表示一个原图像素对应一个屏幕物理像素。
- 编辑窗口可以调整大小、最大化和还原。

### 文字和撤销

文字输入支持中文输入法、选区及常用复制粘贴快捷键。Enter 完成，Shift+Enter 换行，Esc 放弃本次文字修改。

`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做，最多保留最近 24 次修改。关闭有未保存修改的图片时，可以选择保存、放弃或继续编辑。

马赛克会覆盖区域内的其他标注。保存后，标注合并为图片像素；重新打开可以追加标注，但无法单独修改上一次保存的文字或线条。

## 设置

调整外观与动效可以即时预览。点击“保存设置”后长期生效，取消会恢复原设置。

| 页面 | 可调整的内容 |
| --- | --- |
| 常规 | 保存目录、截图快捷键、PrintScreen、预览保留时间、开机自启动 |
| 动效 | 五档动画强度、三种节奏，独立开关启动、截图和拖动动画 |
| 外观 | 薄荷、晴蓝、鸢紫、玫瑰、流金五种强调色，预览位置和尺寸 |
| 截图 | 背景暗度 25%–80%、截图准星 |
| 交互 | 右键定位文件、文件名与操作提示、分享成功后收起 |

预览默认保留到关闭或下一次截图，也可设置为 5、10、15、30、60、120 秒。悬停和拖动期间暂停倒计时。

轻度减少装饰动画；中、高逐渐增加过渡与图片动效；极高和终极提供更丰富的视觉效果。终极滑条使用专属鸢紫色。系统关闭动画时会减少装饰动效，设置滑条仍可正常调整。

开机自启动直接进入托盘。移动 EXE 后，请重新保存设置以更新启动路径。启动动画可以用 Esc / Enter / 空格跳过；终极退出动画可以用这些按键或点击跳过。

## 文件与配置

配置默认位于 `%LOCALAPPDATA%\ScreenShotPlus\config.json`。无法写入时，会尝试使用 EXE 旁的 `ScreenShotPlus-data\config.json`；已有便携配置时优先读取它。设置页会显示当前配置路径。移动便携程序时，请一起保留这个数据目录。

截图写入失败时，图片暂留在内存中。选择可写入的目录并保存设置会自动重试，也可点击“重试保存未保存的截图”。退出程序或完成另一张截图会丢弃尚未保存的旧图片。

## 常见问题

- **快捷键被占用**：在设置中更换组合键，或直接点击截图按钮。
- **PrintScreen 打开系统截图**：在 Windows 设置中关闭“使用 Print Screen 键打开屏幕捕获”，然后启用本程序的 PrintScreen。
- **找不到托盘图标**：检查任务栏的隐藏图标区。图标注册失败时，程序会保留操作面板并重试。
- **无法拖入目标程序**：确认目标支持文件拖入，截图文件仍存在，且两个程序的权限允许拖放；也可以打开保存目录手动添加附件。
- **保存或配置写入失败**：按照页面错误提示，选择当前用户可以写入的位置。程序正常使用不需要管理员权限。

目前不支持录屏、滚动截图、裁剪、旋转和历史管理。受保护的视频、安全桌面及 HDR 色彩还原不在支持范围内。

## 从源码构建

安装 VS 2022 的 C++ 桌面开发工具、Windows SDK 和 vcpkg。打开 `ScreenShotPlus.sln`，选择 **Release / x64** 构建，输出为 `x64\Release\ScreenShotPlus.exe`。

也可运行 `./tools/build.ps1`；添加 `-Test` 执行测试，添加 `-Headless` 跳过窗口测试。构建使用静态运行库，便携 EXE 不需要安装 .NET。
